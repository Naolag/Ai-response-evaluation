Example 1: Concurrency in Databases
  Optimistic concurrency assumes conflicts are rare. Transactions proceed without locks, and conflicts are checked at commit time. If a conflict occurs, the transaction is rolled back.

Example 2: Edge Case in Floating Point Arithmetic
  Because floating point numbers are stored in binary, some decimal fractions cannot be represented exactly. 0.1 and 0.2 are approximations, so their sum is slightly off.
