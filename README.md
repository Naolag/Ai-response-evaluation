# AI Response Evaluation

This repository demonstrates my ability to evaluate AI-generated answers.  
Each example includes:
- **Question.md** → the original prompt
- **ResponseA.md** → AI response A
- **ResponseB.md** → AI response B
- **Ranking.md** → which response is better
- **Reasoning.md** → explanation of ranking
- **FinalVerdict.md** → concise conclusion

## Goal
To show structured reasoning in evaluating AI outputs, focusing on:
- Accuracy
- Completeness
- Clarity
- Code quality (if applicable)
- Edge case handling
